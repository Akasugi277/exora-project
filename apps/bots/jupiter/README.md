# Jupiter Bot (Java)

## Stack

- Language: Java
- Discord framework: Discord4J

## Scope

Jupiter is the Java implementation of the shared Exora bot specification.

## Required environment variables

- DISCORD_TOKEN_JUPITER
- DATABASE_URL
- REDIS_URL

## Next implementation steps

1. Initialize Gradle or Maven project.
2. Add Discord4J dependency.
3. Implement `/ping` slash command.
4. Add PostgreSQL connectivity check on startup.
