# Exora Dashboard Web UI

## Stack

- Framework target: Next.js
- Language: TypeScript

## Purpose

Dashboard for bot status, shared DB health, and command/event observability.

## Required environment variables

- DASHBOARD_PORT
- DATABASE_URL
- REDIS_URL

## Next implementation steps

1. Initialize Next.js with TypeScript.
2. Create status page for 4 bot nodes.
3. Add DB and Redis status indicator.
4. Add basic auth for admin access.
